# official-web-archive

## 项目简介

本项目是一个通用型 HTML 页面归档仓库，用于集中存放和发布多个独立的网页文件。仓库不针对特定域名或网站，而是作为一份静态内容集合，方便对各类页面进行整理、备份与历史查阅。

## 目录说明

```
.
├── pages/          # 存放归档的 HTML 页面文件
├── assets/         # 页面引用的资源文件（图片、样式、脚本等）
├── index.html      # 项目首页，提供归档页面的导航列表
└── README.md       # 本文件
```

## 页面归档说明

- 每个页面以独立 HTML 文件形式存放于 `pages/` 目录下，文件名反映页面主题或归档时间。
- 页面内引用的外部资源（如 CSS、JavaScript、图片等）统一放置在 `assets/` 目录中，确保离线或迁移后仍可正常展示。
- 归档内容保持原始结构，不进行内容修改或重定向。如需标注来源或说明，可在页面内以注释形式记录。

## 维护说明

- 本仓库由维护者不定期更新，新增页面或更新现有页面时，建议同步更新 `index.html` 中的导航链接。
- 归档的页面仅作为资料备份，不保证时效性或外部链接的可用性。
- 如发现页面内容存在明显错误或失效资源，欢迎提交 Issue 或 Pull Request。
- 请勿提交包含恶意代码、侵犯版权或违反法律法规的页面。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 直接在浏览器中打开 `index.html` 即可浏览所有归档页面。
3. 也可通过 GitHub Pages 等静态托管服务部署后在线访问。
